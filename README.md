# Tree Visualizer using React Flow

A React Flow based tree visualization tool that supports:

- Dynamic node creation
- Node renaming
- Expand/collapse functionality
- Search + auto zoom
- Node metadata display
- Hover highlighting
- Minimap and controls
- Auto tree centering

---

## Technologies Used

- React.js
- React Flow
- JavaScript
- CSS
