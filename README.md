# Tree Visualizer using React Flow

An interactive tree visualization tool built using React and React Flow.

---

## Features

### Core Features
- Dynamic tree rendering
- Parent-child edge connections
- Expand/collapse nodes
- Automatic layout recalculation
- Interactive navigation

### Bonus Features
- Search with auto zoom
- Node highlighting
- Node metadata display
- Dynamic node creation
- Node renaming
- Minimap support
- Center tree button
- Smooth interactions

---

## Technologies Used

- React.js
- React Flow
- JavaScript
- CSS
